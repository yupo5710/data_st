자료구조 파이썬 — 제공된 PDF의 구현 방식 기준

1. 실행 방법
Python 3를 사용하며 외부 패키지는 필요 없습니다.
모든 .py 파일을 같은 폴더에 놓고 실행하세요.
예: python ArrayStack.py
예: python MazeBFS.py
파일 맨 아래 if __name__ == "__main__": 아래가 학습용 실행 예제입니다.
다른 파일에서 import하면 예제가 자동 실행되지 않습니다.
예제의 입력 숫자·출력 문구는 이해를 돕기 위해 추가한 것으로, 모두 교재 예제의 전사는 아닙니다.

2. 파일 구성 — 각 파일에 클래스 하나
ArrayList.py / ArraySet.py / ArrayStack.py
CircularQueue.py / CircularDeque.py / PriorityQueue.py
LinkedStack.py / LinkedList.py / LinkedQueue.py / DoublyLinkedDeque.py
Node.py / DNode.py — 필요한 연결 자료구조에서 import하는 보조 클래스
PriorityQueueMaze.py — 교재의 거리 비교용 findMaxIndex 버전
MazeDFS.py / MazeBFS.py / MazeDistance.py — 미로 함수 3종

기본 클래스 12개에, 교재 56쪽의 우선순위 큐 변형을 별도 클래스로 구분한 파일 1개입니다.
미로 코드에서 PriorityQueueMaze를 PriorityQueue라는 이름으로 import하여 교재 함수의 사용 이름을 유지합니다.
교재의 기본 클래스와 거리용 비교 버전을 둘 다 보관하기 위한 파일 분리이며 효율 개선이 아닙니다.

3. 작성 기준
- 교재의 배열/연결 구조, 변수명, 조건문, 반복 순서, 반환 동작을 유지했습니다.
- 임의로 예외를 추가하거나 삭제된 배열 칸을 None으로 비우지 않았습니다.
- 배열 리스트/집합/우선순위 큐의 개수는 정수 속성 size입니다. 예: a.size
- 연결 구조와 원형 큐/덱은 메서드 size()입니다. 예: q.size()
- LinkedStack은 15~20쪽의 기본 순회 버전입니다. 24~25쪽 count 최적화 도전 코딩은 섞지 않았습니다.
- LinkedQueue는 교재의 원형 연결 구조이며 tail.link가 전단입니다.
- CircularDeque는 CircularQueue를 상속합니다. 생성자는 교재처럼 인수 없이 호출합니다.
- ArraySet의 집합 연산은 교재대로 contains/insert를 사용하고 기본 용량의 결과 집합을 만듭니다.
- PriorityQueue 삭제는 교재대로 최대값과 마지막 항목을 교환한 뒤 값을 반환합니다.
- 클래스 코드에 없는 추가 편의 메서드나 도전 문제 정답을 임의로 추가하지 않았습니다.
- 교재가 일부만 보여 주거나 설명만 한 부분은 그 설명에 따라 연결했습니다.
  해당 부분: ArraySet의 생성자/기본 상태 검사/문자열 변환,
  PriorityQueue의 기본 상태 검사, ArrayStack의 문자열 변환,
  DoublyLinkedDeque의 후단 삽입/조회/순회 메서드.
  이 부분은 'PDF에 완성 코드가 그대로 인쇄되어 있다'는 뜻은 아닙니다.

4. 오타 및 표기 불일치 수정 — 알고리즘 변경 없음
- 3주차 33쪽: getEntry의 ps → pos.
- 6장 17쪽: self.n.link → n.link. 같은 쪽 설명에도 n.link로 제시되어 있습니다.
- 스택 51쪽: 통로 비교 '0' → 0. 48쪽 map의 통로가 정수 0이기 때문입니다.
- 큐와 덱 56쪽: self.size() → self.size. 50쪽 클래스에서 size는 정수입니다.
- 큐와 덱 56쪽: self.items → self.array. 50쪽의 저장 배열 이름과 맞췄습니다.
- 큐와 덱 56쪽: 빈 큐의 return None → return -1.
  51쪽 dequeue/peek의 highest != -1 검사와 맞춘 불일치 수정입니다.
- 큐와 덱 57쪽: 출력 q.items → q.array.
위 수정은 해당 코드 줄에도 '교재 원문:'으로 표시했습니다.
미로 출구 좌표는 배열 및 55쪽 거리 함수에 따라 (5,4)입니다.
설명의 (5,3)은 배열과 불일치하며 코드에는 (5,4)를 사용했습니다.
들여쓰기·줄바꿈은 파이썬 파일로 실행할 수 있도록 정리했습니다.

5. 시간복잡도 읽는 법
각 메서드 설명 문자열에 O 표기가 있습니다.
n은 저장 항목 수, m은 상대 집합의 항목 수, capacity는 할당 배열 길이입니다.
원소 비교·대입·원소 하나의 문자열 변환은 O(1)로 가정합니다.
배열 생성 O(capacity), 노드 하나 생성 O(1).
스택 push/pop/peek O(1).
배열 리스트 조회 O(1), 삽입/삭제 최악 O(n).
집합 contains/insert/delete O(n), 두 집합 크기가 비슷하면 집합 연산 O(n²).
원형 큐/원형 덱의 삽입·삭제·조회·개수 O(1).
배열 우선순위 큐 enqueue O(1), findMaxIndex/dequeue/peek O(n).
연결 스택/큐/덱의 삽입·삭제·조회 O(1), 개수 순회 O(n).
연결 리스트 getNode/getEntry/insert/delete 최악 O(n), 머리 작업 O(1).
문자열 변환은 항목 수에 비례하며 임시 리스트가 필요한 경우 추가 공간도 O(n)입니다.
집합 연산은 결과 배열 생성 비용이 별도로 있습니다.

6. 미로 탐색의 교재 동작
DFS(): ArrayStack(100), 상→하→좌→우 순서로 push.
BFS(): CircularQueue(), 상→하→좌→우 순서로 enqueue.
MySmartSearch(): 기본 용량 PriorityQueue(), (x,y,-거리)를 저장.
거리우선은 출구까지의 유클리드 직선거리를 사용합니다. 다익스트라/A*가 아닙니다.
모두 교재처럼 후보를 꺼낸 뒤 map[y][x]='.'로 방문 처리합니다.
중복 후보 제거, 경로 복원, 입력 복사 기능은 추가하지 않았습니다.
반환값은 성공 True, 실패 False입니다. 화면에 출력되는 좌표는 방문 순서입니다.
방문 순서를 실제 이동 경로나 최단 경로로 읽지 마세요.
전역 map이 바뀌므로 동일 프로세스에서 재실행하려면 원래 미로를 다시 지정해야 합니다.
고정 용량도 교재대로 유지했습니다. 예제보다 큰 미로는 용량 때문에 탐색 후보가 누락될 수 있습니다.

미로 복잡도는 V=칸 수, E=인접 관계 수로 표기합니다.
용량이 충분하고 출력 비용을 제외할 때 DFS/BFS O(V+E), 배열 거리우선 최악 O(V²+E).
자료구조 전체 상태를 반복 출력하는 비용은 최악 O(V²)까지 추가될 수 있습니다.
격자에서는 E=O(V)입니다. 교재 예제의 숫자 용량은 위 점근 분석과 구별해야 합니다.

7. 교재 코드의 동작상 주의점 — 임의 수정하지 않음
- 빈 상태의 조회/삭제는 보통 None, 포화 삽입은 아무 일도 하지 않습니다.
- 원형 큐는 한 칸을 비워 두어 실제 저장 한도가 capacity-1입니다.
- CircularQueue.__str__은 27쪽 원문대로입니다. 초기 공백 상태 출력에도 None 칸이 보일 수 있습니다.
- LinkedList는 getNode 결과가 None이면 머리로 취급하는 교재 방식을 유지합니다.
  범위를 벗어난 위치의 동작을 강화하지 않았으므로 정상 위치로 학습하세요.
- LinkedList.delete는 교재처럼 삭제 값 반환이 없습니다.
- ArraySet의 결과 집합은 기본 용량이므로 그 한도를 넘는 합집합은 잘릴 수 있습니다.
- 미로 후보 저장 후가 아니라 꺼낸 뒤 방문 처리하므로 중복 좌표가 출력될 수 있습니다.

스택 LIFO, 원형 큐 회전, 덱 양끝 삭제, 연결 큐의 단일 노드 처리,
집합 연산, 우선순위 순서, 미로 3종의 성공 결과를 확인했습니다.
